# Zoom Mod

Adjust your zoom level with ease in Minecraft.

## Features

- Adjustable zoom level
- Toggle zoom with a key press

## Requirements

- Minecraft 1.18.2
- Forge 40.1.0

## Installation

1. Download the mod from the releases page.
2. Place the mod file in your Minecraft mods folder.
3. Launch Minecraft with Forge.

## Usage

- Press the 'C' key to toggle between zoomed and normal view.

## Configuration

No additional configuration is required. The mod is ready to use out of the box.
